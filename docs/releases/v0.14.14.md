# v0.14.14 — Native online free roam, graphics overhaul, controller feedback

This release brings together all changes in this fork since **v0.14.13**: a redesigned
Underground 2-style interface, live graphics controls, native nfsu2.xyz multiplayer,
rendering optimizations, controller rumble and controller access to mouse-only menus.

## Installation and compatibility

- **ARM64 APK**, Android 10 or newer, Vulkan 1.1-capable device/driver.
- Same development package as the previous fork release: `com.nfsu2.androidevolved.dev`
  (**NFSU2 Native Dev**), version code **29**. It updates the fork's existing app and
  installs beside the upstream production app; it does not replace upstream's package.
- Uses the same signing certificate as v0.14.13. Install over the old fork APK to retain
  app settings. Back up career saves before updating; do not uninstall or clear data.
- Requires your own supported PC game files under `/sdcard/nfsu2/`. No game data,
  texture packs, accounts, Vulkan driver ZIPs or save files are bundled.
- This is still the fork's **debug-signed development channel**, not a new production
  signing identity. APK SHA-256 checksums and a build manifest accompany the download.

## Launcher and interface

- Reworked the launcher around Underground 2's gray, black and lime menu styling:
  condensed fonts, rounded black frames, translucent silver content panels, darker
  option rows, lime values with shadows, and consistent selection/focus outlines.
- Menu headings show the active submenu. Back navigation stays at the top of submenus;
  the main Play/Resume action has a bottom-anchored glowing green shimmer.
- Shorter option labels and clearer grouping: **Graphics setup, Controls, Game, Saves,
  Support**. Improved dialog widths, tablet sizing, action contrast, pickers, toasts,
  benchmark cards and status displays.
- CPU/GPU demand indicators now sit side by side as compact game-style sliders. They
  estimate settings cost; they are not live utilization measurements.
- Driving controls and menu navigation controls now share the same silver/lime theme.
  The driving control dock can collapse behind its top-left expander; editor/dock
  positioning and benchmark overlay dragging were refined.

## Graphics and live adjustments

- New in-game **Graphics** side panel: inspect the actual running scene while changing
  supported settings. The earlier launcher screenshot-preview workflow has been replaced
  by this panel. No animated demo/preview is required.
- Settings grouped by purpose, with live changes distinguished from **NEXT START** values.
  Launch-only choices are not presented as already active in the current game process.
- Color grading includes **Original, Night, Neon night, Filmic and Midnight**; added
  presentation bloom, ordered dithering, revised dark tones and per-look treatment.
- Expanded access to the game's own world/car detail, car shadows and headlights,
  reflection detail/updates, road reflections, fog, rain, particles, light glow/trails,
  motion blur, depth blur, overbright and bleach-bypass settings.
- Graphics settings are owned by the launcher/in-game panel; the original PC Display
  menu is removed from its carousels so it cannot overwrite the port's choices.
- Resolution, frame profiles, frame queue, filtering, sharpening, optional installed
  HD-pack selection and reflection resolution remain available alongside these controls.
- Added optional **FPS counter** in Graphics setup and the in-game Performance controls.
  It measures actual presented frames, uses small muted text at the top right, and
  stops sampling in the background. Default is Off.
- Ray tracing, upscaling and higher-polygon replacement assets are not introduced here.

## Native multiplayer and network modes

- Added **nfsu2.xyz** as a network choice, with a native WebSocket virtual-LAN transport.
  Android can join the service without running the game in a browser.
- Integrated the portable nfsu2-web free-roam client with the native game's main loop,
  including its simulation clock, peer movement, remote-car loading and native host layer.
- Other players can appear in free roam with **names above their cars**, nearby minimap
  markers and **Players** markers on the world map. Name visibility and projection were
  corrected for Android and wide phone aspect ratios.
- Added switch probing/status information and diagnostics. Improved discovery-port
  handling, ICMP forwarding, stale-frame cleanup, announcement handling, reconnect/stop
  behavior and protection against unintended automatic network responses.
- Local **LAN** prefers Wi-Fi and supports the game's same-network discovery path.
  The nfsu2.xyz virtual LAN does not require players to share Wi-Fi.
- The game's **Online / EA Nation replacement** connection remains separate and uses the
  saved online server; selecting the virtual LAN is not an EA-account integration.
- New **Game → Nearby cars** slider accepts every integer **0–32**, default **3**.
  Zero means map-only remote players. This setting requires a fresh game launch.

## Performance, loading and stability

- Reduced repeated native graphics-state submissions with a cache for scalar render and
  texture-stage state. It preserves state-block recording and invalidates on state-block
  application, device changes, reset, shutdown and state restoration. Vendor command
  states bypass the cache.
- Live phone traces show substantial suppression of redundant state setters. This is
  a CPU-overhead reduction, **not a claimed percentage FPS improvement**; GPU draw work
  and car geometry are unchanged.
- Expensive Android remote-car/texture loading is spread across frames instead of
  combining two heavy operations in the same frame. The default remote-car budget was
  lowered, with the full count now user-selectable.
- Added background prefetch for large race assets and warm-up of the last streamed track
  to reduce cold loading stalls. Loading and crowded scenes can still hitch.
- **Quit Game returns to the launcher** instead of an integration-error screen. Added
  missing window destruction/exit handling and fixed NativeActivity lifecycle cleanup
  so the completed game process actually closes.
- Intentional shutdown no longer produces a misleading network reconnect toast.
- Audio output reopens after Bluetooth/headphone routing changes. Disabled Android
  autofill overlays over the game activity.

## Controllers and vibration

- Added menu-only controller pointer support for PC controls outside ordinary focus
  navigation: **right stick moves the mouse pointer; R3 left-clicks**. This includes
  controls such as Quit Game. D-pad/left-stick and A/B navigation remain available.
- While driving, R3 still looks back and right-stick joystick input is preserved.
  Menu pointer input has a dead zone, fine movement response, bounded update rate and
  click release on pause/mode changes. No setting needs enabling.
- Feedback now prefers a connected controller that exposes a vibration motor, falling
  back to the phone when the controller is absent or does not report rumble support.
  Connect/disconnect and resume refresh the output route and cancel the previous motor.
- On compatible controllers exposing two amplitude-controlled channels, effects use
  independent strong/weak rumble instead of sending the same scalar effect to both.
- Shortened surface/curb feedback and removed double gating of traction feedback.
  Traction severity has a stronger response; the latest mapping uses sustained light-motor
  output for traction and an isolated heavy-motor knock with a protected quiet tail for hits.
- Added **Controls → Test traction / Test impact**, using the same output route as gameplay
  so the two cues can be compared without driving. Global vibration strength and the
  Physics/Legacy feedback-source choices remain available.
- Added bounded diagnostic capture of the PC game's original force-effect parameters.
  Physics cues remain slip/impulse estimates, not direct tire-force measurements or an
  exact recreation of PS2 rumble. Latest motor balance remains subject to user tuning.

## Diagnostics, platform work and validation

- Issue reporting and release-note links follow the build's repository/channel, so this
  development APK reports against this fork. Added network and floating-point diagnostics.
- Added a TV launcher entry and a tunable armeabi-v7a source-build target. **This release
  download is ARM64 only**; current 32-bit parity is not established by the ARM64 tests.
- Added/expanded standalone regressions for network frame delivery, haptic envelopes,
  physics scenarios, controller mapping/cursor, widescreen name/HUD projection and
  render-state caching. Graphics resource/device capture-and-restore regressions remain
  part of local validation.
- Phone testing covered native online free roam, visible nameplates/map markers, actual
  FPS output, controller rumble routing and clean Quit Game process teardown. Individual
  latest controller-pointer interactions and the newest haptic distinction still need
  broader device/user validation; not every menu/controller combination has been audited.

## Known limits and upgrade notes

- High remote-car counts, expensive graphics settings and cold asset loads can still
  reduce frame rate. No universal FPS guarantee or matched-scene optimization gain is claimed.
- Multiplayer service availability and cross-client/mode compatibility depend on the
  external services and peers; not every race/lobby combination has been validated.
- Controller rumble capabilities vary by Android driver, controller and Bluetooth/USB
  connection. Reported amplitude support is not calibrated physical precision, and no
  Xbox trigger-motor or arbitrary frequency control is promised.
- **Save states are still experimental and excluded from this APK.** Resume keeps a live
  game session when available; it is not a disk snapshot that survives process death.
- Optional HD packs and custom drivers remain separate user-supplied files. Existing
  save backup/restore and update checking remain available.
